# rsims

**rsims** is an R package for simulating statistical datasets.

It provides reusable helper functions for generating hierarchical data,
random effects, spline functions, latent variable models, state-space
processes, and many ready-to-use simulation scenarios for testing and
benchmarking statistical models.

## Installation

```r
# install.packages("remotes")

remotes::install_github("mlatinov/rsims")
```

## Features

- Hierarchical and crossed data generators
- Random and correlated effects
- Spline and nonlinear simulation helpers
- CFA / SEM simulation helpers
- BSTS and state-space simulation helpers
- Ready-to-use simulation datasets

## Development

The package is under active development and additional simulation scenarios
and helper utilities are added regularly.
